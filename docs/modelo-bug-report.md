# Modelo de Bug Report

Modelo que uso para registrar defeitos. O objetivo é que qualquer pessoa do time consiga **reproduzir o problema sem precisar me perguntar nada**.

---

**Título:** [Módulo] O que acontece + em qual situação
> Exemplo: *[Carrinho] Estoque não é devolvido ao cancelar compra com mais de um produto*

| Campo | Preenchimento |
|---|---|
| **Severidade** | Crítica / Alta / Média / Baixa (impacto técnico) |
| **Prioridade** | Alta / Média / Baixa (urgência para o negócio) |
| **Ambiente** | Versão, URL, navegador ou dispositivo |
| **Usuário / perfil** | Ex.: usuário comum, administrador |

### Pré-condições
O que precisa existir antes de começar (dados, configurações, permissões).

### Passos para reproduzir
1. ...
2. ...
3. ...

### Resultado esperado
O que deveria acontecer, de preferência citando o requisito ou a regra de negócio.

### Resultado obtido
O que aconteceu de fato.

### Evidências
Prints, vídeo, requisição e resposta da API, logs.

### Impacto para o cliente
Como esse problema afeta quem usa o sistema. *(Hábito que trouxe do suporte técnico: ajuda o time a priorizar.)*

### Observações
Frequência (sempre / às vezes), se há contorno, possíveis causas.
